Choose the system you prefer

The head judge can use either TOAST.html or fll-toast-win.exe to generate the closing ceremony script. Both use the saved OJS results and generate the same ceremony output filename, plus a tournament summary. You only need to run one system.

Recommended for ease of use

TOAST.html

Opens in your web browser. Review issues on screen, preview the script, and expand the preview to read the ceremony directly.

Works offline and does not upload your workbooks. No installation is needed.

The system from your training

fll-toast-win.exe

This is the Windows program demonstrated at the start-of-season training. It opens a console window and walks you through the checks and generation prompts.

You may continue using that familiar workflow.

Before using either system

  1. Finish entering the judging and Robot Game scores in your OJS workbook(s).
  2. Confirm the award winners, advancing teams, and alternate selections.
  3. Recalculate, save, and close the OJS files in Excel. TOAST reads the saved workbook; it cannot see unsaved changes.
  4. Keep the tournament files together in the extracted tournament folder. A two-division event needs both OJS workbooks.

Current OJS workbooks already contain their tournament configuration. The browser version includes its ceremony templates. Directors do not need to edit a configuration file or install Python.

Option A: use TOAST.html

  1. Double-click TOAST.html to open it in a browser. Chrome and Edge have been tested for this version.
  2. Click Choose files and select your OJS workbook. For a two-division tournament, select both files together. You can also drag them from the tournament folder onto TOAST.
  3. Review the detected tournament and validation results. If a score is missing or invalid, TOAST identifies the worksheet, cell, and team to check.
  4. Fix any issues in Excel, recalculate, save, and close the workbook. Return to TOAST and click Check again. If your browser cannot reopen the selected files directly, it will ask you to select them again.
  5. Review any warnings. If an allocated award will intentionally have no winner, review the omissions and type exactly YES. Those places will appear as NONE. Otherwise, correct the selections in the OJS.
  6. Click Preview ceremony to review the closing ceremony, and Preview summary to check the award and advancement summary.
  7. Click Download ceremony and Download summary to save your final documents. Your browser chooses where to save them, commonly the Downloads folder.
Reading the ceremony from TOAST?

In the ceremony preview, click Expand preview. The script fills the browser window so an emcee can read and scroll through it. Click Return to TOAST to restore the normal layout, or Close preview to close it. The summary preview can be expanded too.

Expanding the preview does not save a copy. Download the final ceremony as well so you have a backup if the TOAST page is closed or refreshed. Use your browser’s zoom controls to adjust text size.

New selections and repeat checks clear earlier warning and omission approvals. Review and approve the current results before downloading or previewing documents.

Option B: use the familiar Windows program

  1. Keep fll-toast-win.exe in the same folder as the OJS workbook(s) for this tournament.
  2. Double-click fll-toast-win.exe. A console window opens, as demonstrated during training.
  3. Confirm the tournament information and follow the prompts. If validation finds issues, correct them in Excel, recalculate, save, close Excel, and run the program again.
  4. Review warnings and any missing-award prompts carefully. Type YES only when leaving the listed allocated awards unpresented is intentional.
  5. After successful generation, find the closing ceremony and summary HTML files in the tournament folder. Double-click them to read them in a browser.

The Windows executable is still available for those who prefer the trained workflow. If Windows prevents it from running, contact your tournament organizer, or use TOAST.html.

Find and use the final documents

Closing ceremony script
A filename ending in -closing-ceremony.html. This is the script for your emcees.
Tournament summary
A filename ending in -summary.html. This records award winners, advancing teams, and alternates.

Both systems generate the same output filenames for the same OJS selection. The browser normally downloads them; the executable writes them into the tournament folder. When regenerating, make sure the emcees use the latest copy. Your browser may add a suffix such as (1) rather than replace an older download.

Review the team names, award presentation order, advancement announcements, and emcee highlighting before the ceremony. Open a downloaded document in a browser to read it or use the browser’s Print command to print or save a PDF.

If something needs attention

A score is missing or invalid
Start with the worksheet and cell TOAST identifies. Fix the score, recalculate and save in Excel, then check again.
Saved totals or rankings are out of date
Recalculate the workbook in Excel, save and close it, then check again. If the message persists, ask the tournament organizer to check the workbook formulas.
A division is missing or the files belong to different tournaments
Select only this tournament’s OJS workbook(s), including both divisions when applicable.
You need help from the organizer
In browser TOAST, click Download diagnostic report and provide that report with a description of the problem.
